# v0.3.5 — OpenCode V2 与 CodeBuddy

2026-11-05。

## OpenCode 默认 V2

新项目直接运行：

```sh
mini-trellis init -u your-name --opencode -y
```

已有 V1 项目保留原入口；旧版宿主可显式加 `--opencode-version 1`。两种协议共用知识技能和项目 Markdown。切换到 V2 前先用 `mini-trellis refresh --opencode --opencode-version 2 --dry-run` 预览，确认后去掉 `--dry-run`。

配置更新保留用户插件、SDK 版本与依赖；本地修改冲突会在写入前提示。卸载时保留共享的 OpenCode package.json。

## CodeBuddy CLI 与 IDE

```sh
mini-trellis init -u your-name --codebuddy -y
```

两端共用项目配置、启动入口和技能，只需安装一次。使用 `mini-trellis-remember` 技能记录结论；CLI 也可用 `/mini-trellis:remember`。通过 `mini-trellis mem recall` 找回知识，摘录不足时用 `mem read` 展开。

重复安装、刷新和从 Trellis 迁移时保留用户 hook、环境与权限。OpenCode V2 和 CodeBuddy 都可召回已保存的项目知识；原始对话历史检索继续支持 OpenCode V1。

## 升级

```sh
npm install -g mini-trellis@0.3.5
mini-trellis refresh --dry-run
mini-trellis refresh
mini-trellis doctor
```

完成后开启新会话。详见[日常使用](/zh/using/)和[升级指南](/zh/upgrade/)。
