# v0.4.1 — 新增 Google Antigravity 支持

2026-11-19。

Antigravity 可以和 Codex、ZCode 共用同一份项目知识。在一个 Agent 里确认的规则，换到另一个 Agent 也能从项目里找到。

- 通过 `mini-trellis init --antigravity` 安装三项共享技能，用于记录决定、查找项目知识和更新规范。
- 在支持 `SessionStart` 的版本中，新会话会收到项目入口。启动信息带有当前目录或只提供工作区路径时，都能定位项目。
- 使用 `mini-trellis refresh --antigravity` 更新配置，使用 `mini-trellis doctor` 查看 Hook 的注册和最近执行情况。迁移会保留本地改过的 Trellis 工作流和技能。
- 已保存的项目规则用 `mini-trellis mem recall` 查找。要整理某次 Antigravity 对话，可以提供 Markdown 或纯文本导出。

## 为项目添加 Antigravity

在项目根目录执行，再开启新的 Antigravity 会话。

```bash
mini-trellis init --antigravity -y
mini-trellis doctor
```
