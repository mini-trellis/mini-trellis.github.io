# v0.3.6 — 选定历史整理为项目知识

2026-11-06。

## 整理选定历史

让 `mini-trellis-session-insight` 把选定会话或提供的 Markdown/文本导出整理成可复用的项目知识。更新已有 README、docs、spec 或 research 主题，保留来源与纠正，核对保存内容后记录 journal 链接。材料没有新知识时，文档和日志保持原样。

```text
请用 mini-trellis-session-insight 整理 exports/callback-chat.md，更新已有项目文档。
保留确认结论、纠正、例外和来源；存在冲突的决定集中向我提问。
```

已有文档沿用原语言，已确认需求、已实现行为和建议分别标明状态。下一次会话用 `mini-trellis mem recall "回调规则"` 找回知识并用于开发。

原始会话读取支持 Claude Code、Codex、OpenCode V1 和 Pi；其他宿主使用 Markdown/文本导出。整理流程记录主题链接时使用 `--no-commit`。

## OpenCode V1 召回

`mem recall` 每次查询只读取一次共享 SQLite message/part 数据，并在候选会话间复用，消除了逐个会话重复扫描整个数据库造成的等待，包括没有匹配结果的查询。

## 升级

```sh
npm install -g mini-trellis@0.3.6
mini-trellis refresh --dry-run
mini-trellis refresh
```

刷新后开启新会话。见[完整示例](/zh/using/#把选定聊天整理成项目知识)和[升级指南](/zh/upgrade/)。
