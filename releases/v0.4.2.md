# v0.4.2 — Factory Droid and project memory fixes

2026-11-21

Factory Droid can load project memory at session start and read local conversation history. Migration preserves user handlers and JSONC comments. Rewinding in Droid 1.17.0 creates a separately searchable session. Select the fork’s ID to review work after the rewind.

Cursor migration keeps custom hooks and one managed startup entry. Recording stops before writing if its input file cannot be read. Chinese queries can find rule text ahead of a matching TODO title, and a single Markdown reference can show both a current rule and a rejected proposal within the default read budget.

To add Droid, run these commands in the project root and open a new Droid session.

```bash
mini-trellis init --droid -y
mini-trellis doctor
```
