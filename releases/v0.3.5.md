# v0.3.5 — OpenCode V2 and CodeBuddy

2026-11-05.

## OpenCode defaults to V2

For a new project, run:

```sh
mini-trellis init -u your-name --opencode -y
```

Existing V1 projects keep their entry; pass `--opencode-version 1` for a V1 host. Both protocols share knowledge skills and project Markdown. Before switching to V2, preview with `mini-trellis refresh --opencode --opencode-version 2 --dry-run`, then repeat without `--dry-run`.

Configuration updates preserve user plugins, SDK versions, and dependencies. Local edits are reported before conflicting writes. Uninstall preserves the shared OpenCode package.json.

## CodeBuddy CLI and IDE

```sh
mini-trellis init -u your-name --codebuddy -y
```

Both interfaces share project settings, the startup entry, and skills in one installation. Record conclusions with the `mini-trellis-remember` skill; CLI also offers `/mini-trellis:remember`. Find knowledge with `mini-trellis mem recall`, then expand incomplete excerpts with `mem read`.

Repeated installation, refresh, and migration from Trellis preserve user hooks, environment, and permissions. OpenCode V2 and CodeBuddy recall saved project knowledge; raw conversation history search remains available for OpenCode V1.

## Upgrade

```sh
npm install -g mini-trellis@0.3.5
mini-trellis refresh --dry-run
mini-trellis refresh
mini-trellis doctor
```

Then start a new chat. See [Day to day](/using/) and [Upgrade](/upgrade/).
