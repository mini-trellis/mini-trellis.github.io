# v0.3.8 — Kiro, Pi / OMP and automatic refresh

2026-11-11.

- Adds Kiro CLI V3 / IDE 1.x project skills and a SessionStart entry. See [Kiro setup](/using/#kiro).
- Adds native OMP extensions, prompts and skills under `.omp/`. See [Pi / OMP setup](/using/#pi-and-omp).
- Fixes Pi remember argument forwarding. Use `/mini-trellis-remember <decision>` to record confirmed knowledge and `mini-trellis mem recall <query>` to retrieve it later.
- Fixes refresh manifest mismatches after initialization with a custom Python command. Normal managed updates complete directly; content conflicts receive one Y/N confirmation. Y applies replacements; N or Enter keeps the project unchanged. Shared JSON settings merge user fields and project knowledge stays in place.
- Starting with 0.3.8, `upgrade` updates the CLI and automatically refreshes the current initialized project using the new templates.

## First upgrade to 0.3.8

Run from the project root:

```bash
npm install -g mini-trellis@0.3.8
mini-trellis refresh
mini-trellis doctor
```

An upgrade started by 0.3.7 or earlier needs this manual refresh. Direct npm updates are also followed by `mini-trellis refresh`. Refresh each project you use, then start a new agent session. See [Upgrade](/upgrade/).
