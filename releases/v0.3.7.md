# v0.3.7 — ZCode project knowledge and history reading

2026-11-09.

## Use project knowledge in ZCode

Use `--zcode` to install a project startup entry and the remember, session-insight and update-spec skills. ZCode and Codex share the same skills under `.agents/skills/`.

```bash
mini-trellis init -u your-name --zcode -y
```

In ZCode Desktop, open **Settings → Hooks**, select this project, review and trust `.zcode/hooks/session-start.py`, then start a new session. Standalone CLI setup is in [Day to day](/using/#zcode-zai).

Record confirmed decisions in existing topics and link them from the journal. In the next chat, use `mem recall` to find the knowledge and `mem read` to expand missing conditions. Organize supplied Markdown/text into project docs, keeping the existing document language. After compact, follow `AGENTS.md` to read saved knowledge and skills.

Installation and refresh preserve user configuration, hooks and other skills. Review changed hook declarations in ZCode after refreshing.

## Read complete characters and identify partial history

Claude Code, Codex and Pi JSONL readers preserve complete UTF-8 characters across chunk boundaries, including Chinese and emoji.

Malformed or truncated events produce a warning with the source file, first affected line and count. Valid records remain available, and recall results are marked `incomplete` so you can identify material that needs completing.

## Upgrade

```bash
npm install -g mini-trellis@0.3.7
mini-trellis refresh --dry-run
mini-trellis refresh
mini-trellis doctor
```

To add ZCode to an existing project, run `mini-trellis init --zcode -y`, review and trust the project hook, then start a new session.
