# v0.3.6 — Selected history into project knowledge

2026-11-06.

## Organize selected history

Ask `mini-trellis-session-insight` to organize selected sessions or supplied Markdown/text exports into reusable project knowledge. It updates the existing README, docs, spec or research topic, keeps sources and corrections, and records a journal link after checking the saved content. Unchanged material leaves the documents and journal as they are.

```text
Use mini-trellis-session-insight to organize exports/callback-chat.md.
Update the existing project docs, keeping confirmed decisions, corrections,
exceptions and sources. Ask about conflicting decisions together.
```

Existing documents retain their language. Confirmed requirements, implemented behavior and suggestions remain distinct. In the next chat, use `mini-trellis mem recall "callback rules"` to find the knowledge for development.

Native session readers support Claude Code, Codex, OpenCode V1 and Pi. Other hosts can supply Markdown/text exports. The organizing flow uses `--no-commit` when recording the topic link.

## OpenCode V1 recall

`mem recall` now reads the shared SQLite message/part store once per query and reuses it across candidate sessions. This removes the repeated full-database scans that could leave a query waiting even when nothing matched.

## Upgrade

```sh
npm install -g mini-trellis@0.3.6
mini-trellis refresh --dry-run
mini-trellis refresh
```

Start a new chat after refreshing. See [the full example](/using/#turn-selected-chats-into-project-knowledge) and [Upgrade](/upgrade/).
