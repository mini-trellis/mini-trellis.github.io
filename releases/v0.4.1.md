# v0.4.1 — Google Antigravity

2026-11-19.

Antigravity can use the same project knowledge as Codex and ZCode. A rule recorded in one agent is available to the others in the same project.

- Add Antigravity with `mini-trellis init --antigravity`. The three shared skills record decisions, find project knowledge, and update specifications.
- On versions that support `SessionStart`, a new session gets a short project entry. The hook locates the project from the workspace paths or the current directory.
- Use `mini-trellis refresh --antigravity` to update the integration and `mini-trellis doctor` to check its registration and recent execution. Migration preserves locally edited Trellis workflows and skills.
- To revisit an Antigravity conversation, supply a Markdown or plain-text export. Saved project knowledge is searchable with `mini-trellis mem recall`.

## Add Antigravity to a project

Run these commands in the project root, then open a new Antigravity conversation.

```bash
mini-trellis init --antigravity -y
mini-trellis doctor
```
