# mini-trellis

mini-trellis stores the conventions, research, and session notes you want a later coding session to find. The docs site is <https://mini-trellis.github.io/>.

```bash
npm install -g mini-trellis
mini-trellis init -u your-name --claude
```

Source code: <https://github.com/Tiger-zzZ/mini-trellis>

## Keeping the site current

The source repository's README, `docs/using*.md`, migration guides, and release notes are the content sources for this site. Synchronize the English and Chinese pages together; publishing source-repository changes does not deploy this repository.

Keep the home-page release notice, `_config.yml` callout, and release list aligned with npm. Publish user-facing capabilities, usage, upgrade instructions, and version records. Keep benchmark numbers attached to the version measured.
