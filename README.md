# mini-trellis

mini-trellis stores the conventions, research, and session notes you want a later coding session to find. The docs site is <https://mini-trellis.github.io/>.

```bash
npm install -g mini-trellis
mini-trellis init -u your-name --claude
```

Source code: <https://github.com/Tiger-zzZ/mini-trellis>
